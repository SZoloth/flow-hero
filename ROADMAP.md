# Roadmap

What's planned for flow-hero, in build order. Each item is a GitHub issue with what it should look like, starting points and when it counts as done, so a person or a coding agent can pick one up.

1. [Materials: one simulation, several looks](https://github.com/SZoloth/flow-hero/issues/1). Adds `ink.material` (`smoke`, `cloud`, `water`). The foundation for 2 and 3, with no visual change to today's presets.
2. [Cloud material](https://github.com/SZoloth/flow-hero/issues/2). Lit, billowing clouds with bright edges, on sky or dark gradients, plus a thunderstorm look where lightning lights the clouds from inside.
3. [Water material](https://github.com/SZoloth/flow-hero/issues/3). The pointer makes ripples that refract the background, plus an ink-in-water variant.
4. [Dynamic colour](https://github.com/SZoloth/flow-hero/issues/4). Colour that cycles over time, follows stroke speed or direction, or changes as ink ages. A layer any patch can switch on, for every colour setting and every material.

Ideas and requests: [open an issue](https://github.com/SZoloth/flow-hero/issues/new).
